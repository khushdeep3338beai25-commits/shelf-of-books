
# 📚 SHELF OF BOOKS — Digital Library

SHELF OF BOOKS is an interactive digital library designed to make discovering and exploring books a delightful experience. Featuring a curated collection across multiple genres and categories, the website combines the timeless charm of traditional bookshelves with a clean, modern digital interface.

🌐 **Live Website:** https://shelf-of-books-two.vercel.app/

---

## ✨ Features

- 📚 **Digital Bookshelf** — Explore a beautifully organized collection of books.
- 🔍 **Book Discovery** — Browse and discover books across different genres.
- 🗂️ **Multiple Categories** — Explore curated collections and book genres.
- 📖 **Book Information** — View book titles, authors, and publication details.
- 🎨 **Modern UI/UX** — Clean, elegant, and editorial-inspired design.
- 📱 **Fully Responsive** — Optimized for desktop, tablet, and mobile devices.
- ⚡ **Smooth Interactions** — Enjoy an intuitive and seamless browsing experience.

## 🎨 Design Philosophy

SHELF OF BOOKS brings together the nostalgia of traditional libraries and the simplicity of modern web design.

The design focuses on:

- Minimal and elegant aesthetics
- Refined typography and visual hierarchy
- Carefully organized book collections
- Intuitive navigation and accessibility
- A reading-focused browsing experience

## 🛠️ Technologies Used

- **HTML5** — Website structure and semantic markup
- **CSS3** — Styling, layouts, animations, and responsiveness
- **JavaScript** — Interactive elements and dynamic functionality
- **Vercel** — Deployment and hosting

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd day-076-shelf-of-books
```

**3. Open the project**

Open `index.html` in your browser or use the Live Server extension in VS Code.
