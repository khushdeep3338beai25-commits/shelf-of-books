
# 📚 SHELF OF BOOKS

### An Interactive Digital Library

A beautifully designed digital bookshelf that brings together a curated collection of books across multiple genres and categories. Discover books, explore collections, and enjoy a clean, immersive browsing experience.

🌐 **Live Website:** https://shelf-of-books-two.vercel.app/

---

## ✨ Features

- 📖 Interactive digital bookshelf
- 🔍 Explore and discover curated book collections
- 📚 Multiple book categories and genres
- 📝 Book details, authors, and publication information
- 🎨 Clean, modern, editorial-inspired design
- 📱 Responsive layout for different screen sizes
- ⚡ Smooth and intuitive browsing experience

## 🎨 Design Philosophy

SHELF OF BOOKS combines the charm of traditional libraries with a modern digital experience.

- Minimal and elegant aesthetics
- Thoughtful typography
- Organized book collections
- Intuitive navigation
- Focus on readability and visual presentation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Vercel
